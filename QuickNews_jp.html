「野球って何が起こるかわからない」

　＜本盗を許した経験は？＞

　捕手人生で初めて決められました。まさかそれが社会人野球の舞台で起きるとは思っていなかったので……。自分も想像していなかったプレーが起きたので、焦りと何が起こったかわからなかったというのがあります。本当に野球って何が起こるかわからないっていうのを感じました。

　＜今後への意気込みをお聞かせください＞

　自分のプレッシャーに勝てるかどうかが試される世界だと思うので、バッティングなどの技術面もそうですが、頭も鍛えていく必要があると考えています。

　生活経済課によると、4人の逮捕容疑は2023年8月ごろから24年1月ごろまでの間、県内の20代の男女2人に対し、オンラインカジノで高い利益を出せるなどとうその投資話を持ちかけ、アドバイザー業務の委託料として、それぞれ100万円をだまし取ったというもの。県警は4人の認否を明らかにしていない。

俺は昔、貧しくて…

　被害者の説明などを基にした、県警の見立てはこうだ。

　まず「勧誘役」の容疑者の男女2人が、マッチングアプリで異性と知り合う。

　居酒屋や飲食店で複数回食事をして恋愛感情を抱かせた後、資産運用の話を切り出す。

　胸騒ぎは的中した。送られてきた動画には、灰色の濁流が荒れ狂う様子が映っていた。場所はネパール中部ゴルカ郡、ヒマラヤ山脈の麓を流れるブディガンダキ川流域。8月下旬に岩石と氷の崩落で大惨事が発生した「ギロン・ラスワ回廊」から、50〜60キロほど西だという。少なくとも5人が行方不明となり、住宅や橋、水力発電所などが被害を受けた。

　ヒマラヤ地域の環境を監視する政府間機関「国際総合山岳開発センター（ICIMOD）」によると、8月の大惨事発生前の48日間に、最大40センチの地盤変動が衛星レーダーで検出されていたという。「衛星監視の活用でリスクが高い斜面を特定し、より詳細な観測が可能になる」が、既存の警戒システムでは突発的な山体崩壊などを事前に検知することは困難だという。ラスワ回廊で2025年7月に起きた氷河湖決壊による洪水は突然だった。10月の土石流に関しては、よく分かっていない。

　世界が一丸となって解決に動く状況には程遠い。それどころか、温室効果ガスを大量に排出する軍事活動は拡大の一途をたどっている。大国が関与する戦争は周辺国の軍備増強を招いているが、軍事活動でどれほどのCO2が排出されているかは正確に公表されていない。地球全体が破滅への連鎖に巻き込まれているかのようだ。

　だが新たな動きもある。相次ぐ災害を経て「気候変動は人権問題」との考え方が世界的な共通認識となりつつある。国際司法裁判所（ICJ）や欧州人権裁判所などは2024年から2025年にかけ、政府が気候変動対策を怠ることは人権侵害や国際法違反に当たるとの勧告を出した。「健康で持続可能な環境で暮らす権利」や「将来世代の権利」を守るため、司法が対策を促す推進力となり始めている。

　ただ悲観しているだけでは始まらない。そう思い直した。

第140回広州交易会（Canton Fair）、海外バイヤー来場者数が過去最多を記録して閉幕、国際貿易への信頼感を示す

中国・広州、2026年11月6日 /PRNewswire/ — 第140回中国輸出入商品交易会（China Import and Export Fair、通称Canton Fair）が11月4日、広州で閉幕しました。 今回の交易会には、219の国と地域から過去最多となる35万2,000人の海外バイヤーが来場し、前回比12.2%増となりました。会場での輸出成約意向額は267億5,000万米ドルに達し、中国製品やサプライチェーン分野での提携に対する世界的な需要が引き続き堅調であることを示しました。

国際的なつながりの強化とビジネス機会の創出

主要市場でバイヤーの参加が拡大し、欧州連合からの来場者数は38.2%、米国からは22.2%、一帯一路構想（BRI）の協力国からは16.6%増加しました。専門バイヤーが海外来場者全体の75%超を占めました。世界有数の国際調達企業500社以上が交易会に参加しました。

サンフランシスコ, 2026年11月6日 /PRNewswire/ — Redisは本日、AIエージェント向けリアルタイムコンテキストエンジン「Redis Iris」の新たな展開を発表しました。Redis Irisは、組み合わせても個別でも利用でき、エージェントが実環境で安定して動作するために必要なメモリ、コンテキスト、メッセージングを提供する6つのカスタマイズ可能な機能、すなわちRedis Intent Router、Redis Agent Playbooks、Redis Agent Memory、Redis Context Gateway、Redis Lens、Redis Agent Meshを備えています。

AIモデルとインフラストラクチャは現在、エンタープライズ用途に十分な水準に達していますが、エージェントによって本番運用レベルの成果を安定して再現できているチームはごくわずかです。エージェントでは、必要なコンテキストが、必要なタイミングで適切な形で記憶されていないことが少なくありません。価値を生み出している場合でも、情報を詰め込みすぎたプロンプト、冗長なLLM呼び出し、壊れやすいカスタム統合などによって非効率になり、生み出す価値以上のトークンと時間を消費することがよくあります。

「エージェントには、アプリやマイクロサービスと同じ基盤が必要です。具体的には、リアルタイムのアプリデータ、ランタイム状態、サービス間通信です」とRedisのCEO、Rowan Trollopeは述べました。「さらに、メモリ、コンテキスト管理、ルーティングといった新たな機能も必要です。Redisはすでに、アプリケーション向けの主要なランタイムデータベースとしてホットパス上で稼働しています。開発者がエージェントを動作させるために、5つものインフラストラクチャ製品を必要とするべきではありません。Irisはこれらの基本要素を1か所にまとめ、開発者が本番環境で動作するエージェントを構築できるようにします。」

6つの機能、1つのランタイム

Irisは、導入時点から本番運用に対応したコンテキスト、メモリ、メッセージングを提供すると同時に、各チームがエージェントに合わせてそれぞれの機能をカスタマイズできるようにします。今回のリリースには以下が含まれます。

・Intent Router (GA)は、リクエストの文言ではなく意味を照合し、保存済みのFAQ、エージェントスキル、人間、LLMのいずれであっても、適切な処理先に振り分けます。また、エージェントとモデルのルーティング、ガードレール、「ファジー」なif文もサポートするため、判断が真か偽かの二択に限定されません。・Agent Playbooks (GA)を使用すると、どの回答が安定していて再利用すべきか、どの回答に最新データと既知の手順の新たな実行が必要かをチームが定義できます。Playbooksは実行を重ねるほど内容が充実し、精度が向上するため、解決時間とトークン消費量を削減できます。・Agent Memory (GA)は、MemoryETLを通じてユーザーの操作、ドキュメント、その他の半構造化データからメモリを構築し、よりきめ細かな制御ができるよう階層構造に整理するとともに、検査、監査、データの来歴確認機能を提供します。また、個人を特定できる情報など、保持すべきでない情報を忘れることもできます。・Context Gateway (GA)は、接続されたコンテキストソースにアクセスするための、一元的に管理された単一のエントリポイントをエージェントに提供します。チームは独自のMCPサーバーを利用し、特定の問題を解決するのにどのツールを使うべきかをキャッシュしてトークン使用量を削減するとともに、セッション間で一貫性を確保するため、結果を再利用可能な形で構築できます。・Lens (beta)は、エージェントの動作を追跡可能にします。すべての結果について、その結果を提供したスキル、ルート、FAQ、学習に使用したメモリ、ソースセッションまで遡って追跡できるため、監査可能な証拠に加え、タスクの成功、タスクごとのトークン数、レイテンシに関する可視性も得られます。・Agent Mesh (beta)は、エージェントが一時的なストリームを介して通信できるようにし、接続が切れると自動的にバッファリングして再接続します。Durable SSE Streamsは中断が発生しても応答を流し続け、A2A Commsはエージェントの委任や引き継ぎに信頼性の高いチャネルを提供します。

これらの機能を組み合わせることで、エージェントが適切な情報を記憶し、適切な形で回答し、あらゆる行動の透明性を確保しながら、1トークン当たりの成果を増やすことができます。Irisはチームがすでに使い慣れているRedisテクノロジー上で動作するため、組織は通常、検索、メモリ、ルーティング、メッセージングをつなぐために必要となるカスタム統合作業を削減できます。

複雑な現実世界に対応する設計

本番環境で稼働するエージェントは、人間からの予測不能な入力、複数のチャネル、エージェント間の引き継ぎに対処する必要があり、そのいずれも障害点になり得ます。Irisは4つの原則に基づいて構築されています。コンテキストはサイロ化せず横断的にたどれるようにし、メモリは適応的かつ選択的に機能し、コストを抑えるためコンテキストを効率的に扱い、さらにエージェントが過去のやり取りから学ぶにつれてコンテキストが蓄積され、価値を増していくようにするべきです。

Redisについて

Redisは世界最速のデータプラットフォームです。2011年にオープンソースとして誕生して以来、キャッシングソリューションで最も多く引用されるブランドとなったRedisは、1万社を超える顧客による、世界を支えるアプリケーションの構築、拡張、展開を支援してきました。キャッシングやGenAIなどに対応するクラウドおよびオンプレミスのデータベースにより、Redisはデジタルビジネスがアプリの速度に新たな標準を打ち立てるのを支援します。

サンフランシスコ、オースティン、ロンドン、テルアビブ、シンガポールに拠点を置くRedisは、高速なアプリを迅速に構築する分野のリーダーとして世界的に認められています。詳細については、redis.ioをご覧ください。
